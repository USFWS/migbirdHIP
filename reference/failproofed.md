# Fail if non-proofed data frame supplied

Internal function that fails if a tibble without `errors` field
(generated by
[`proof`](https://usfws.github.io/migbirdHIP/reference/proof.md)) is
provided.

## Usage

``` r
failProofed(proofed_data)
```

## Arguments

- proofed_data:

  The object created after error flagging data with
  [`proof`](https://usfws.github.io/migbirdHIP/reference/proof.md)

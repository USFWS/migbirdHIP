# Label dates for issue date plot

The internal `issuePlotDateLabel` function labels x-axis dates for
[`issuePlot`](https://usfws.github.io/migbirdHIP/reference/issuePlot.md).

## Usage

``` r
issuePlotDateLabel(x)
```

## Arguments

- x:

  Vector of dates

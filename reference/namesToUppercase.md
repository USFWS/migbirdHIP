# Names to uppercase

The internal `namesToUppercase` function converts name elements to
uppercase for easier string cleaning.

## Usage

``` r
namesToUppercase(raw_data)
```

## Arguments

- raw_data:

  The object created after reading in data with
  [`read_hip`](https://usfws.github.io/migbirdHIP/reference/read_hip.md)

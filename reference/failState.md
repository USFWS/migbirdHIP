# Fail if bad state abbreviation supplied

Internal function that fails if a bad state abbreviation is provided.

## Usage

``` r
failState(state)
```

## Arguments

- state:

  Any abbreviation for one of the 49 contiguous states:

  - AL, AK, AZ, AR, CA, CO, CT, DE, FL, GA, ID, IL, IN, IA, KS, KY, LA,
    ME, MD, MA, MI, MN, MS, MO, MT, NE, NV, NH, NJ, NM, NY, NC, ND, OH,
    OK, OR, PA, RI, SC, SD, TN, TX, UT, VT, VA, WA, WV, WI, WY

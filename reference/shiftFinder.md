# Find frame shifts

The internal `shiftFinder` function finds any rows that have a line
shift error.

## Usage

``` r
shiftFinder(raw_data)
```

## Arguments

- raw_data:

  The object created after reading in data with
  [`read_hip`](https://usfws.github.io/migbirdHIP/reference/read_hip.md)

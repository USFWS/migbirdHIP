# Find duplicates

Determine how many duplicate records are in the data and return a table.

## Usage

``` r
duplicateFinder(current_data)
```

## Arguments

- current_data:

  The object created after filtering to current data with
  [`issueCheck`](https://usfws.github.io/migbirdHIP/reference/issueCheck.md)

# Check for frame shifts

Find and print any rows that have a line shift error with number of
positions shifted.

## Usage

``` r
shiftCheck(raw_data)
```

## Arguments

- raw_data:

  The object created after reading in data with
  [`read_hip`](https://usfws.github.io/migbirdHIP/reference/read_hip.md)

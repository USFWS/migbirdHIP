# Check for repeat files

Check if any files in the input folder have already been written to
processed folder.

## Usage

``` r
fileCheck(raw_path, processed_path)
```

## Arguments

- raw_path:

  Directory of the download folder containing HIP .txt files

- processed_path:

  Directory of the folder containing processed files

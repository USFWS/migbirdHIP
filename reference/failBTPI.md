# Fail if BTPI permit file contains bad values

Internal function that applies to BTPI permit files.

## Usage

``` r
failBTPI(corrected_data)
```

## Arguments

- corrected_data:

  The object created after correcting data with
  [`correct`](https://usfws.github.io/migbirdHIP/reference/correct.md)

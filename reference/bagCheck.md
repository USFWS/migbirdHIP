# Check bag values

After fixing the data with
[`duplicateFix`](https://usfws.github.io/migbirdHIP/reference/duplicateFix.md),
see if any unexpected bag values were submitted.

## Usage

``` r
bagCheck(deduplicated_data)
```

## Arguments

- deduplicated_data:

  The object created after deduplicating data with
  [`duplicateFix`](https://usfws.github.io/migbirdHIP/reference/duplicateFix.md)

# Create a tibble of duplicates with an ID column

Return a tibble of duplicates with a duplicate ID column identifying
each group of records.

## Usage

``` r
duplicateID(current_data)
```

## Arguments

- current_data:

  The object created after filtering to current data with
  [`issueCheck`](https://usfws.github.io/migbirdHIP/reference/issueCheck.md)
